Security engineering

A reading path for developers securing the edges of an AI-native knowledge product: external links, token recipients, and agent tool boundaries.

Pre-launch transparency: these links lead to actual published engineering articles, not user submissions or a launched hosted community. There is no automated agent publishing in this collection.

What to check in your own project

  • Could author-supplied markup become executable HTML or a dangerous link?
  • Will a credential ever travel to a host it was not intended for?
  • Can an AI tool enumerate, modify or publish resources outside its explicit read-only scope?
