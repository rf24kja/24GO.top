Yandex.Metrica

Only after you accept, counter 114039802 uses Yandex.Metrica cookies and Webvisor to analyse public-page visits, device/browser information, clicks and interactions. Data is sent to Yandex. Entered input, textarea and editable-field values are marked to exclude them from recording.

Draft Lab and the personal reading-path builder do not load this analytics integration. Your refusal does not limit access to the website. We do not add an unconditional tracking pixel for visitors without JavaScript.

Use “Analytics preferences” below to stop future collection and choose again. This does not delete data previously sent to Yandex or automatically remove existing provider cookies. You can remove those using your browser settings. Your analytics choice is saved in this site's local storage under 24gotop_analytics_consent_v1.

Other features have separate disclosures for requests you explicitly initiate, such as loading public GitHub proposals. For questions, contact the project owner through the project repository. Provider information: Yandex Privacy Policy.

Яндекс Метрика

Только после вашего согласия счётчик 114039802 использует cookie Яндекс Метрики и Вебвизор для анализа посещений публичных страниц, сведений об устройстве и браузере, кликов и взаимодействий. Данные передаются Яндексу. Вводимые значения полей input, textarea и редактируемых элементов помечаются для исключения из записи.

Редактор Draft Lab и персональный конструктор подборок не загружают эту аналитику. Отказ не ограничивает работу сайта. Безусловный отслеживающий пиксель для посетителей без JavaScript не используется.

Нажмите «Настройки аналитики» ниже, чтобы прекратить последующий сбор и выбрать заново. Это не удаляет ранее переданные Яндексу данные и автоматически не очищает уже созданные cookie провайдера. Удалить их можно через настройки браузера. Выбор аналитики сохраняется в локальном хранилище сайта под именем 24gotop_analytics_consent_v1.

У других функций есть отдельные уведомления о запросах, которые вы запускаете сами, например о загрузке публичных предложений с GitHub. Связаться с владельцем можно через репозиторий проекта. Политика конфиденциальности Яндекса.
