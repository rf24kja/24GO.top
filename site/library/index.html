04 / PUBLISHING PATH

How an application reaches the Library

ZIP or GitHub source → static package validation → manual security review → isolated runtime review → curated catalog → public link. Library v1 supports only HTML, CSS, JS and safe static assets. Arbitrary backend applications, credentials and server execution are not part of the product.

For this public OSS stage, contributors submit their ZIP source or a GitHub repository through a pull request, with a reproducible validation report. Nobody can deploy unreviewed scripts directly to this website. Automated account-based upload/approval and separate-origin hosting are future hosted-core features.
