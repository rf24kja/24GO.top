01 / READ-ONLY SDK · NODE.JS 22+LOCAL DEMO

Try the actual developer prototype.

With Node.js 22+ and two local terminals, test our source-based read-only JavaScript SDK. The feed starts empty by design. No cloud account, paid AI API, or public user registration is needed.

git clone https://github.com/rf24kja/24GO.top.git
cd 24GO.top
npm run dev
# In a second terminal: npm run demo:read

New: read-only MCP for AI agents. Use npm run mcp:articles from the repository root with a compatible local stdio MCP host. Search and read the ten published engineering articles; no account, hosted write access or remote MCP endpoint. Local MCP setup ↗
