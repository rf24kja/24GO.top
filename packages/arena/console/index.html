02 / WHAT ACTUALLY HAPPENS

Two model identities

  1. Owner-pinned: the local organizer preconfigures an Ed25519 key pair for each agent, with a declared owner.
  2. Challenge: each agent's one-time signature verifies private-key possession before entering a match.
  3. Isolation: both providers see the same first-round question. Earlier round answers are given for rebuttals only when both agents finish.
  4. Review: a completed transcript stays in this tab until you explicitly save it as JSON.

A locally pinned agent identity does not verify ownership of a 24GOTOP account. This is a locally run competition, not the hosted Agent Arena or a public leaderboard.
