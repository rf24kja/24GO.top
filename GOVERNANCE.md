# 24GOTOP Project Governance

**Founder and project lead:** [@rf24kja](https://github.com/rf24kja)  
**Official repository:** https://github.com/rf24kja/24GO.top  
**Canonical product domain:** https://24go.top

24GOTOP is a founder-led initiative that welcomes ideas, constructive discussion, bug reports, documentation, translations and code contributions. Community collaboration does **not** transfer control of the official project or its operational infrastructure.

## Founder responsibilities and decisions

- Define mission, roadmap, product quality and official branding.
- Control the official domain, administrative accounts, infrastructure, production deployments and releases.
- Review or delegate technical review of Pull Requests; authorize merges to the official repository.
- Define and enforce coherent project participation rules, security requirements and licensing choices within applicable law and existing grants.
- Credit other contributors for their original work. Authorship/copyright of independently contributed code is determined by law and applicable licenses or agreements, not by GitHub admin permissions.

## Contributors

Anyone may propose features, discuss improvements, report issues or submit Pull Requests, subject to GitHub policies and the Code of Conduct. Contribution does not automatically make someone a cofounder, shareholder, administrator, product owner or commercial licensor of 24GOTOP. Maintainer permissions, if granted later, are operational roles, not an ownership transfer.

GitHub public repositories can be viewed and forked. The current [MIT LICENSE](LICENSE) expressly permits broad use of code already released under that license. This document **does not override that license** or revoke past grants.

## Decisions and accountability

Significant changes follow: public Issue / RFC → trade-offs, risk & rollback → PR with tests → CI → review → maintainer approval → Changelog/Decision Log update. External contributors should receive credit in commits/PRs and release notes where appropriate.

The primary project owner has final responsibility for official 24GOTOP product direction, while technical correctness, safety and feedback remain open to constructive challenge.

## Licensing review

The founder has asked to preserve ownership of the official hosted platform and to avoid distributing its complete future commercial implementation. A possible approach is **private production core + genuinely open developer SDK/MCP/API packages + public docs and community**.

**This is an architectural proposal, not a new code license.** Do not merge a replacement license, rewrite Git history, close the repository or move code without documenting compatibility, contributors' rights and impact on the existing MIT release. See [IP and Licensing Strategy](docs/IP_AND_LICENSING.md).
