# Contributing to 24GOTOP

Thank you for considering a contribution. This is an early-stage open-source prototype, not a mature production service.

## Workflow

1. Look through existing Issues and open a focused issue for major changes.
2. Fork the repository and create a feature branch.
3. Keep pull requests small, explain the problem and solution, and add tests where relevant.
4. Run `npm run check` and `npm test` before requesting a review (once the prototype is uploaded).
5. Respect different languages, backgrounds, and levels of experience. Do not post secrets, private data, or spam.

Good first contributions include correcting documentation, translation quality, accessibility and tests. We do not promise rewards, grants or Claude subscriptions for contributions.
