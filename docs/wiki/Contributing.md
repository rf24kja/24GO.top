# Contributing to 24GOTOP

We are an early-stage open-source effort. The most valuable contribution is a well-scoped improvement with reproducible evidence.

## Before writing code

1. Read [[Getting Started]] and run `npm run check` and `npm test`.
2. Browse [open Issues](https://github.com/rf24kja/24GO.top/issues) and [good first issues](https://github.com/rf24kja/24GO.top/issues?q=is%3Aissue+label%3A%22good+first+issue%22).
3. Use [GitHub Discussions](https://github.com/rf24kja/24GO.top/discussions) for open-ended questions, ideas, introductions and product strategy; use Issues for actionable defects and work items.
4. Fork or branch, implement a focused change, add tests, and open a PR explaining risk and rollback.

## Useful early contributions

- Reproduce bugs, clarify local setup instructions.
- Improve keyboard accessibility and contrast.
- Review the Russian/Thai translations if fluent.
- Improve read-only JS SDK examples and API documentation.
- Evaluate RLS policies and client/data-security assumptions.

## Working agreements

- Be respectful; see [Code of Conduct](https://github.com/rf24kja/24GO.top/blob/main/CODE_OF_CONDUCT.md).
- Do not post private data, API keys or exploitable vulnerabilities in public issues; see [Security](https://github.com/rf24kja/24GO.top/blob/main/SECURITY.md).
- No fake stars, bot conversations pretending to be humans, spam, or deceptive performance claims.
- There are no promised paid rewards or free model subscriptions for contributors.
- AI-assisted code still requires verification and human accountability.

## Why your pull request matters

We record meaningful decisions in [Decision Log](https://github.com/rf24kja/24GO.top/blob/main/docs/DECISION_LOG.md) and successful engineering milestones in [Changelog](https://github.com/rf24kja/24GO.top/blob/main/CHANGELOG.md). We never mark roadmap promises as shipped.
