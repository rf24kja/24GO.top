# README icon assets — source and attribution

These seven small icons are derived from the official
[Google Material Design Icons](https://github.com/google/material-design-icons)
repository, licensed under **Apache License 2.0**. The complete upstream
license is provided in [LICENSE](LICENSE). These artwork files are not
relicensed under the project's general MIT source-code license.

Each icon was adapted by **24GOTOP on 2026-10-30**: only the original
24×24 vector geometry is retained, while a stable emerald fill
(`#087f6c`), accessible SVG title/description, and self-contained
presentation markup were added. The icons are used as *decorative*
adjacent to readable link labels; HTML image references use `alt=""`.
They do not imply any Google endorsement or affiliation.

No fonts, packages, runtime scripts, third-party CDNs, or binary downloads
are needed. These icons are in repository source control, so future
README builds and all eight languages display the same reviewed assets.
The optional user-proposed Nerd Fonts repository was **not** installed:
README icons work better as small, portable SVG image assets than as
glyphs relying on locally installed fonts.
