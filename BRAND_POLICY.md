# 24GOTOP Brand and Attribution Policy

**Project:** 24GOTOP (also styled 24GO.top).  
**Founder / official project lead:** [@rf24kja](https://github.com/rf24kja).  
**Official domain:** https://24go.top  
**Official GitHub repository:** https://github.com/rf24kja/24GO.top

The founder intends 24GOTOP to have a distinctive, independently controlled identity. The brand name, logos, visual identity, domain and official-project designation are separate from copyright licenses for source code.

## What participants are welcome to do

- Link to the official site or GitHub repository, quote the project's name factually and credit the original project.
- Publish accurate reviews, tutorials, bug reports, compatibility notes and independent integrations.
- Clearly identify nonofficial forks, experiments or derivative projects as **independent** rather than as official 24GOTOP deployments.

## Uses requiring agreement with the founder

Ask the project lead before presenting a separate service as an **official 24GOTOP service**, using the project's branding in a manner likely to confuse users about affiliation, or claiming sponsorship, endorsement, partnership or administrative authority.

The project may later publish a detailed logo-usage guide and request formal trademark registration. No trademark registration, geographic exclusivity or court-established rights are claimed here. The scope of any enforceable rights depends on applicable law and prior usage.

## Important: code license is separate

The repository currently contains software distributed under the [MIT license](LICENSE), which permits reuse, redistribution, commercial use and deployment **of that code** under its stated conditions. This brand guide does not rescind or contradict the MIT grant or create a ban on running copies. It addresses official identity and misleading affiliation, within applicable law.

If the founder decides to reserve proprietary future platform code, it must be kept outside public MIT-licensed releases and handled with documented lawful licenses and contributor permissions.

For licensing / brand inquiries, open a non-confidential Discussion addressed to the maintainer. For sensitive matters use GitHub's private contact mechanisms; do not disclose personal identity documents or credentials publicly.
